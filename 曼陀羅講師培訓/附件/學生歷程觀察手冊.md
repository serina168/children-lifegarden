# 一、一條線：歷程觀察 vs 畫面解讀

## 唯一合法的判讀來源

**你親眼看到的創作歷程行為。**

| ✅ 可以寫 | ❌ 絕對不可寫 |
|---|---|
| 「他每次都等別人先動筆才開始」 | 「他畫黑色代表情緒低落」 |
| 「他畫壞就整張換掉，一堂換三張」 | 「畫面空白代表內心孤單」 |
| 「他上色前一定先問老師可不可以」 | 「線條用力代表有攻擊性」 |
| 「他完成後主動拿給三個同學看」 | 「畫在角落代表缺乏自信」 |
| 「他這次用了六種顏色，上次兩種」 | 「用色變多代表心情變好」 |

**判準只有一句**：你是用**眼睛看到的行為**，還是用**畫面推測的內心**？
前者可寫，後者一律刪除。

## 為什麼不能從畫面判讀

1. **沒有實證基礎。** 顏色與線條的心理意義，沒有可靠的對照關係。
2. **變因太多。** 今天穿的衣服、上一堂看到的東西、最喜歡的卡通、離他最近的那支筆。
3. **超出權責。** 心理判讀需要專業訓練與執照，那不是美術講師的範圍。
4. **會傷人。** 一句錯誤的推論，可能跟著孩子好幾年。

## 但歷程觀察真的有用嗎——三個用途

| 用途 | 在哪裡兌現 |
|---|---|
| **說對那一句話** | U09 五向度回應對照表 |
| **給家長看得懂的成長** | U11 家長訊息、U12 期末報告 |
| **交接給下一位老師** | U12 第 7-4 節 |

# 二、五個觀察向度

**十二個單元累積下來，每個孩子的五個向度都會被看過至少兩次。**

| 代號 | 向度 | 觀察的問題 | 在教室看什麼 | 深寫的單元 |
|---|---|---|---|---|
| **①** | **起動** | 從指令結束到第一筆落下，中間發生什麼？ | 秒數・是否等待・是否先看別人 | U01（無結構）U04（有結構）U10（班級） |
| **②** | **持續** | 遇到不會的地方，第一反應是什麼？ | 求助／停滯／跳過／自己試 | U02（耐力型）U03（技能型）U10（班級） |
| **③** | **決定** | 需要自己決定時，他怎麼決定？ | 自己決定／問老師／照抄／不決定 | U03・U05・U06 |
| **④** | **容錯** | 出現他認為的失誤時，會發生什麼？ | 修補／覆蓋／換紙／揉掉／繼續 | U06・U08 |
| **⑤** | **連結** | 完成後怎麼對待作品與他人？ | 主動分享／藏起來／比較／命名 | U01・U07・U08・U11 |

## 兩個關鍵的分辨

**① 起動：有結構 vs 無結構**

| | U01 無結構（自由塗鴉） | U04 有結構（摺紙） | 這告訴你 |
|---|---|---|---|
| 情況一 | 立刻開始 | 立刻開始 | 起動能力穩定 |
| 情況二 | 遲疑很久 | 立刻開始 | 他需要**明確的第一步**，不是鼓勵 |
| 情況三 | 立刻開始 | 遲疑很久 | 他怕**做錯**，要多說「差不多就好」 |
| 情況四 | 兩種都遲疑 | | 需要長期起動支持，見第八章 |

**② 持續：撐不下去 vs 不想撐**

| | 撐不下去 | 不想撐 |
|---|---|---|
| 看到的 | 手停、揉手腕、身體滑下椅子 | 東張西望、找人講話、玩材料 |
| 通常是 | **生理疲勞** | **動機流失** |
| 該做的 | 插入身體活動、縮短任務 | 給看得見終點的小目標、加難度變數 |
| 不該做的 | 要求「再撐一下」 | 要求「再認真一點」 |

**這兩者處理方向完全相反。判斷錯了，會越處理越糟。**

# 三、事實句怎麼寫

## 三個檢查問題

寫完每一句，問自己：

1. **你在哪一堂、什麼時候看到的？** → 答不出來，刪掉。
2. **這句話能被替換成別的孩子嗎？** → 可以，就是通用句，不是觀察。
3. **有沒有出現性格詞？**（內向、自信、細心、沒耐心）→ 全部改寫成行為。

## 錯誤示範對照（依向度）

**① 起動**

| ❌ 推論句 | ✅ 事實句 |
|---|---|
| 他很沒自信，不敢畫。 | 指令結束後約 4 分鐘才畫第一筆，期間看了鄰座三次。 |
| 他很依賴別人。 | 示範結束後未動作，看鄰座摺完第一次才開始。 |
| 他不聽指令。 | 未摺紙直接畫；問他時說「這樣比較快」。 |

**② 持續**

| ❌ | ✅ |
|---|---|
| 他沒有耐心。 | 第 32 分鐘後停筆 3 次，每次約 1 分鐘，有揉手腕。 |
| 他過動。 | 整堂離座 4 次，每次 2–3 分鐘，都在段落二之後。 |
| 他很被動。 | 卡住時停下來等待，未舉手，等了 2 分鐘。 |
| 他後來就放棄了。 | 第一段落點了 60 個點，第三段落只點了 15 個。 |

**③ 決定**

| ❌ | ✅ |
|---|---|
| 他很猶豫，缺乏主見。 | 色卡填寫費時約 3 分鐘，擦改 2 次。 |
| 他心情比較低落。 | 整張使用藍與深藍；問理由時回答「我喜歡藍色」。 |
| 他沒信心，要看別人。 | 選色時看色相環 2 次、看鄰座 1 次。 |

**④ 容錯**

| ❌ | ✅ |
|---|---|
| 他有完美主義傾向。 | 本堂換紙 3 次，都在畫眼睛時。 |
| 他容易放棄。 | 發現不對後停筆 8 分鐘，未求助。 |
| 他很有創意，心理素質好。 | 第二隻眼睛較大後，加了一圈羽毛把小的補齊。 |

**⑤ 連結**

| ❌ | ✅ |
|---|---|
| 他很膽小。 | 拿到花後未主動觸碰，觀察 5 分鐘後才摸花瓣。 |
| 他很沒自信。 | 上色時以手臂圈住畫紙；分享時未舉起。 |
| 他很外向。 | 交換花材時主動說「我的花瓣有 18 片，你的呢」。 |
| 他不在乎自己的作品。 | 說明卡「我最喜歡這裡」欄空白；被問時說「不知道要寫什麼」。 |

## 紀錄的時機

- **課中**：只在觀察表上打勾與寫關鍵詞（最多五個字）。
- **課後十分鐘內**：補完整句子。**超過半天，細節就不可靠了。**

# 四、三種高價值紀錄格式

一般的行為紀錄只告訴你「他怎麼樣」。下面三種格式告訴你「**接下來該怎麼做**」。

## 格式 A｜介入 → 反應

> 我做了什麼 ＋ 他變成怎麼樣

| 範例 |
|---|
| 「卡在換色時停 2 分鐘，未求助；**提供紅卡後**，本堂使用紅卡 1 次。」 |
| 「離座 4 次皆在段落二之後；**發通行證後**，下一堂離座 1 次。」 |
| 「鱗片第一次失敗後改畫圓點；**拆成『只畫三個』後**願意重試，完成 6 個。」 |
| 「色卡 3 分鐘完成、擦改 2 次；**限縮為 6 色後** 20 秒內決定。」 |
| 「20 公分圓對摺失敗 3 次；**換 15 公分圓後**成功。」 |
| 「說『你沒有換紙，你把它修好了』；**本堂未再要求新紙**（前三堂各換 2–3 次）。」 |

**為什麼最有價值**：它告訴你**什麼對這個孩子有效**。
這是唯一能交給下一位老師、也能講給家長聽的東西。

## 格式 B｜首次出現的行為

> 第一次＿＿

| 範例 |
|---|
| 「本堂為**首次**主動使用色相環（前三堂皆看鄰座）。」 |
| 「**首次**主動與同儕互動（前六堂皆無）。」 |
| 「本學期**首次**自願導覽；向 2 位客人說完三句腳本。」 |
| 「**第一次**沒有問我就自己開始畫。」 |

**為什麼重要**：⑤ 連結與 ① 起動的成長，幾乎都是以「第一次」的形式出現的。
**錯過就沒了。** 所以觀察表要放在手邊。

## 格式 C｜跨單元／跨時間對照

> 第 ○ 堂＿＿ → 最近＿＿

| 範例 |
|---|
| 「U01（無結構）第一筆前 4 分鐘；U04（有結構）示範後即開始。→ 需要明確第一步。」 |
| 「第一堂起動 5 分鐘、看鄰座 3 次；第十堂起 1–2 分鐘內開始、未再看鄰座。」 |
| 「第五堂選色 3 分鐘擦改 2 次；第十堂 20 秒決定並能說出理由。」 |

**兩點連成線，才叫觀察；單點只是印象。**
從 U04 開始，每次寫紀錄前先回頭翻一次上一次同向度的紀錄。

# 五、四種樣貌速查

> 每一格的「這通常反映什麼」都只能解釋到**發展階段或學習習慣**的層次，
> 一律使用「通常」「多半」「可能」，不得寫成斷定，不得使用診斷詞。

## ① 起動（U01 無結構情境）

| 樣貌 | 看到什麼 | 通常反映 | 第一句話 |
|---|---|---|---|
| A 立刻下筆 | 指令沒說完就開始 | 對材料熟悉、接近傾向強 | 「這一圈你想重複，還是變化？」 |
| B 先看別人 | 看兩三個同學才動筆 | **正常的社會學習策略** | 「這支金色的給你用，全班只有你有。」 |
| C 反覆確認 | 每畫一個就問「可以嗎」 | 在別處學過「畫錯會被糾正」 | 「可以。從現在開始不用問我。」 |
| D 凍結 | 握筆五分鐘不動 | 不確定正確答案 | （並肩坐下自己畫）「幫我決定——圓的還是尖的？」 |

## ① 起動（U04 有結構情境）

| 樣貌 | 看到什麼 | 通常反映 | 第一句話 |
|---|---|---|---|
| A 照步驟做 | 動作跟示範一致 | 程序性任務表現穩定 | 「這一圈我沒有示範，你自己決定。」 |
| B 先看再做 | 要看鄰座做一次才跟上 | **一次記不住三個步驟**（正常） | 「這一張是摺好的，你可以看著做。」 |
| C 跳過步驟 | 不摺直接畫，「這樣比較快」 | 還沒體會結構的價值 | （拿有／無摺痕兩張對比）「你看這張擠在一起了。」 |
| D 手上做不到 | 摺不齊、越摺越歪 | 雙手協調未到位 | 「我們換小張一點的。」（降階，不要求他） |

## ② 持續（U02 耐力型）

| 樣貌 | 看到什麼 | 通常反映 | 第一句話 |
|---|---|---|---|
| A 穩定推進 | 節奏平均，中途不抬頭 | 難度剛好 | 「你這一圈的點，間距一直一樣。」（別忽略他） |
| B 衝刺後熄火 | 前十分鐘飛快，後段停擺 | **還沒有分配力氣的概念** | 「這一圈剩八個點，點完就休息。」 |
| C 卡住就等人 | 停下來安靜等老師 | 過去「等待有效」 | 「卡住時把紅卡立起來，我就會過來。」 |
| D 逃離 | 頻繁上廁所、喝水 | **離座是一種自我調節** | 「這節課你有兩張通行證。」 |

## ② 持續（U03 技能型）

| 樣貌 | 看到什麼 | 通常反映 | 第一句話 |
|---|---|---|---|
| A 挑戰 | 專挑三顆星，失敗再畫 | 有「練了就會」的成功經驗 | 「你這個鱗片畫了三次，第三次整齊很多。」 |
| B 安全牌 | 只畫圓點直線 | **合理策略，在保護成功經驗** | 「鱗片就是一排彎彎的線，我們先畫一排就好。」 |
| C 卡住就換 | 畫歪就改畫別的 | 還沒有「重來一次」的概念 | 「我們只畫三個。三個畫完就成功。」 |
| D 卡在筆上 | 握太緊、指節發白、甩手 | **握筆或筆具不合手** | （換粗筆）「小指頭貼在紙上。」 |

## ③ 決定

| 樣貌 | 看到什麼 | 通常反映 | 第一句話 |
|---|---|---|---|
| A 快速決定 | 20 秒填完色卡，不換色 | 有清楚偏好 | 「你的主角為什麼選這個顏色？」（問理由） |
| B 參照 | 看色相環、看範例才決定 | **最健康也最常見**（工具被用起來了） | 「你想找熱鬧的還是安靜的？」 |
| C 猶豫 | 填了擦、擦了填、反覆問 | **選項太多**造成決策超載 | 「今天你的顏色只有這六個。」（減少選項） |
| D 單色 | 整張一到兩色 | 可能是**風格**，也可能是迴避 | 「你整張都用藍色，是故意的嗎？」（真心問） |

**分辨 D 的方法**：有理由＋態度肯定＋上色仔細 → 是風格，不要動它。
說不出理由＋草率＋想結束 → 比較接近迴避，同樣貌 C 處理。

## ④ 容錯（觀察切片：第二隻眼睛畫歪了）

| 樣貌 | 看到什麼 | 通常反映 | 第一句話 |
|---|---|---|---|
| A 修補 | 加一圈羽毛把小的補齊 | 已有「錯誤可以處理」的經驗 | （說給全班聽）「他加了一圈就變一樣了，這是設計師的做法。」 |
| B 覆蓋 | 用深色塗掉 | 讓它消失，也是一種策略 | 「蓋起來也可以。也可以讓牠變成在眨眼睛。」 |
| C 換紙 | 一堂換兩三次，都卡在眼睛 | **心中標準高於現在的手** | 「今天每個人有兩張紙。這裡卡住了，我有兩個辦法……」 |
| D 停擺 | 不修不蓋不換，停十分鐘 | **手上沒有任何處理策略**（最需要介入，也最安靜） | 「這裡不太一樣大。」（停兩秒）「這樣，或這樣。你要哪一個？」 |

## ⑤ 連結

| 樣貌 | 看到什麼 | 通常反映 | 第一句話 |
|---|---|---|---|
| A 全面投入／想被看見 | 主動摸實物、自願導覽、帶人來看 | 對此環境有安全感 | 「你剛剛發現的，跟大家說一下。」 |
| B 想參與不想講 | 願意掛出但不導覽 | **展示與發言是兩種能力** | 「你要不要當掛畫組長？」（不用開口的參與） |
| C 作品獨占／不想掛 | 手臂圈住畫、說「我不要掛」 | 還不確定作品會被怎麼對待 | 「不掛也可以。有四個辦法你可以選……」 |
| D 不碰／無所謂 | 拒絕碰實物、外框隨便做 | **先想生理**（過敏、觸感）**再想心理** | 「那我們用看的就好。」／「一定要選一張掛，你會選哪張？」 |

**⑤ 連結的鐵則**：**絕對不勸說、不點名、不用「就講一句就好」誘導。**
強迫內向的孩子公開發言，換來的是他下次連作品都不想掛。

# 六、表單

## 表單一｜五向度單堂觀察表（A4 橫式，每堂一張）

課中只打勾與寫關鍵詞，下課後十分鐘內補句子。

| 姓名 | ① 起動<br>（第一筆前幾分／有無看人） | ② 持續<br>（卡住時） | ③ 決定 | ④ 容錯 | ⑤ 連結 | 關鍵詞（≤5 字） |
|---|---|---|---|---|---|---|
|  | ___ 分　□看人 | □求助 □停滯 □自試 | □自己 □問師 □照抄 | □修 □蓋 □換 □揉 □續 | □主動 □被動 □藏 □命名 |  |
|  | ___ 分　□看人 | □求助 □停滯 □自試 | □自己 □問師 □照抄 | □修 □蓋 □換 □揉 □續 | □主動 □被動 □藏 □命名 |  |

**使用說明**
- 一張表填 15 人；每堂**只重點記錄 4–5 位**，輪流覆蓋全班，一學期每人被記 3–4 次。
- 該堂的重點向度以外，欄位空白無妨。
- **輪替原則**：用座位表輪流，不要每次都挑同樣的孩子——尤其不要只挑最需要幫助的那幾個。

**各單元的重點向度**

| 單元 | 重點記錄 |
|---|---|
| U01 | ① 起動（無結構）・⑤ 連結 |
| U02 | ② 持續（耐力型） |
| U03 | ② 持續（技能型）・③ 決定 |
| U04 | ① 起動（有結構）＋**回頭對照 U01** |

# 七、談話腳本

## 對孩子：五向度回應對照表

> **同一句鼓勵，對不同向度困難的孩子，效果天差地遠。**
> 這張表是整本手冊最實用的一頁。

| 向度 | 困難 | ❌ 無效（雖然是好意） | ✅ 有效 | 為什麼 |
|---|---|---|---|---|
| ① 起動 | 不知道怎麼開始 | 「加油，你可以的」 | 「你今天自己開始畫了。」<br>「上次你等了五分鐘，今天兩分鐘就動筆了。」 | 他需要的不是打氣，是**看見自己啟動了** |
| ② 持續 | 撐不到最後 | 「再撐一下就好了」 | 「你已經畫了十五分鐘，你的手很努力。」<br>「這一圈你沒有停下來。」 | 把**時間本身**變成成就 |
| ③ 決定 | 不敢／不會選 | 「你自己決定就好」 | 「這個顏色是你自己選的。」<br>「你猶豫了一下，然後選了紫色。」 | 肯定**做決定這個動作**，不是結果 |
| ④ 容錯 | 畫壞就崩潰 | 「沒關係啦，不醜」 | 「這裡本來不一樣大，你加了一圈就變一樣了。」<br>「你沒有換紙，你把它修好了。」 | 指出他**處理錯誤的方法**，讓方法被記住 |
| ⑤ 連結 | 不敢給人看 | 「不要害羞，舉起來」 | 「你今天讓我看了。」<br>「你剛剛主動去看別人的畫。」 | 肯定**跨出的那一小步**，不要求更大的 |

## 對家長

**原則：只說行為與變化，不說原因與判斷。**

| ✅ | ❌ |
|---|---|
| 「這三堂課他開始不問我就自己選顏色了。」 | 「他比較沒有安全感，所以需要一直確認。」 |

**四個常見情境**

| 家長問 | 怎麼回 |
|---|---|
| 「他有沒有進步？」 | 「我看的是他自己的變化——第一堂要等五分鐘才敢下筆，上禮拜兩分鐘就開始了。前三堂畫錯就換紙，這一堂他自己把不對稱的地方補起來了。」 |
| 「他畫得好不好？」 | 「畫得好不好是我的標準，不是他的。技巧會自己長出來，但『敢開始』和『不怕犯錯』要練很久。如果您想看技巧，我指給您看他線條的變化。」（拿第一張與最後一張對照） |
| 「他畫這樣代表什麼？」 | （必背三句之一，見第八章） |
| 「他怎麼都用同一個顏色？」 | 「顏色的選擇跟很多事有關——今天離他最近的是哪支筆、最近喜歡什麼卡通。我不會從顏色判斷孩子的心情，那不準。我看到的是：他這三堂都很快決定、中途沒改、每張都塗完了。」 |

## 對導師

**原則：說你已經做的，再問對方的觀察。不給結論。**

| ✅ | ❌ |
|---|---|
| 「我把材料改成三個站、動一動提前到 20 分，第三組還是會在後半段吵。想問您他們在班上的座位是怎麼安排的？」 | 「他們班很難帶。」 |
| 「他這三堂課都是等 5 分鐘以上才動筆，我想問問他在您課堂上的狀況。」 | 「他好像有注意力的問題。」 |
| 「他前半學期都會幫作品取名字，最近三堂都空白。想跟您確認最近有沒有什麼變化。」 | 「他最近怪怪的，是不是家裡有事？」 |

# 八、轉介與通報流程

## 判準：只有三類訊號

**行為（做了什麼）・語言（說了什麼）・身體（看到什麼）。**
**畫面不在其中。作品的顏色與構圖，永遠不是轉介或通報的依據。**

## 分級處理

```
【當堂即處理】
　自傷動作（打自己／戳自己／咬）
　攻擊他人（推／打／丟東西）
　離開教室去向不明 > 10 分鐘
　　↓ 停止創作、確保安全 → 同日反映導師與主管

【1 次即通報｜24 小時內】
　① 描述被傷害的經過，或身上有非意外性傷痕
　② 表達不想活、想消失、想傷害自己
　③ 透露長期無人照顧、沒有食物、獨自在家過夜
　　↓ 單位主管 ＋ 學校輔導室

【觀察 2–3 堂後與導師交換】
　持續無法起動（有／無結構皆然）
　持續自我貶低，不因具體肯定而改變
　原本會的變得不會（**倒退比停滯更值得注意**）
　對多種材料有觸覺或嗅覺排斥
　握筆／摺紙困難，換工具後仍無改善
　　↓ 導師 → 必要時輔導室或建議家長諮詢專業
```

## 24 小時通報四步驟

| 步驟 | 做什麼 | 注意 |
|---|---|---|
| 1. 當下 | 維持平常反應，不追問，不表現震驚 | 你的反應會決定他下次還說不說 |
| 2. 課後立即 | 書面記錄：時間、地點、在場者、**孩子的原話**、你的處置 | 只寫事實與原話 |
| 3. 24 小時內 | 通報單位主管 ＋ 學校輔導室 | 依貴單位窗口與表單 |
| 4. 後續 | 依指示配合 | **你是通報者，不是處理者** |

**不做的事**：不聯絡家長詢問、不告訴其他家長、不在教師群組討論、
**不把孩子的作品當作證據附上**、不在孩子面前表現任何異樣。

## 必背三句（結構：說事實 → 表明界線 → 指路）

**① 家長問「他畫這樣代表什麼？」**
> 「畫面本身沒辦法告訴我們孩子的心理狀態，顏色跟線條受很多因素影響。
> 我可以告訴您我在課堂上實際看到的：他今天畫得很專心，而且完成了。
> 如果您對他最近的狀況有疑慮，跟導師或輔導老師談會比較適合。」

**② 孩子說了一半又不說**
> 「好，你想說的時候再說。我在這裡。」（然後真的走開）

**③ 同事問「那孩子是不是家裡有問題？」**
> 「我在課堂上看到的部分，我已經跟導師反映了。其他的我不太清楚。」

## 通報紀錄表

見 L1-U08 附件五（完整格式）。核心欄位：
時間地點／在場人員／當時活動／**我看到的**／**孩子說的話（逐字＋引號）**／我的處置／通報對象與時間。

**填妥後交單位主管，不留副本在個人處，不拍照、不上傳雲端。**

# 九、期末學生觀察報告

## 一頁式格式

```
【○○○ 這學期的畫畫紀錄】　　　　　　　○○ 學年 ○○ 學期

一、他完成了什麼
　　出席 ___ / ___ 堂　完成作品 ___ 件　參與的活動：__________

二、我看到的五個變化
　① 起動：第一堂 ______ → 最近 ______
　② 持續：第一堂 ______ → 最近 ______
　③ 決定：第一堂 ______ → 最近 ______
　④ 容錯：第一堂 ______ → 最近 ______
　⑤ 連結：第一堂 ______ → 最近 ______

三、三個具體的時刻（前／中／後段各一）

四、下學期我會繼續注意的地方
```

## 四條寫作規則

| # | 規則 |
|---|---|
| 1 | **只寫看到的**——每句都要能回答「你在哪一堂看到的？」 |
| 2 | **用前後對照**——單一時間點的描述沒有意義 |
| 3 | **不寫性格**——不寫內向、自信、沒耐心 |
| 4 | **第四項寫自己**——「我會怎麼做」不是「他應該怎樣」 |

## 每一格應該長成這樣

```
① 起動：第一堂從指令結束到第一筆約 5 分鐘，會先看鄰座；
　　　　第十堂起約 1–2 分鐘內開始，未再看鄰座。
```
**時間點 ＋ 具體行為 ＋ 對照。三個要素缺一不可。**

## 四種難寫的報告

| 情況 | 怎麼寫 |
|---|---|
| **五向度都沒有明顯變化** | 誠實寫「無明顯變化」。18 小時對某些孩子本來就不足以產生行為改變；也可能起點值就高。重點放在第三項的三個時刻。第四項：「下學期我會把觀察重點放在 ○ 向度。」 |
| **有向度倒退** | 只寫**時間點＋客觀情境**的並列，**不寫因果**。例：「第一至七堂皆會發言；第八堂起未再發言（第八堂為情緒主題）。」並且——倒退應在發現當下就與導師交換，不要拖到期末。 |
| **我寫不出這個孩子的事** | **不要編。** 第三項有幾件寫幾件。第四項誠實寫：「這學期我對 ○○ 的觀察紀錄較少。下學期我會用反向巡桌法，每堂優先走他的座位。」——這樣寫需要勇氣，但比漂亮的空話有價值。 |
| **有需要轉介的訊號** | **期末報告不是通報文件。** 仍然只寫行為與變化，不寫通報內容、不寫轉介建議、不寫診斷性描述。通報走各自的正式管道。 |

## 交出去前的自我檢查五問

| # | 問題 | 沒通過怎麼辦 |
|---|---|---|
| 1 | 每一句都能回答「哪一堂看到的」？ | 答不出來的，刪掉 |
| 2 | 有沒有性格詞？ | 全部改寫成行為 |
| 3 | 五向度是不是都用「第一堂 → 最近」？ | 補上時間點 |
| 4 | 第四項主詞是不是「我」？ | 改寫 |
| 5 | 有沒有寫到私密書寫或通報內容？ | 全部刪除 |

## 交接給下一位老師

| 交接什麼 | 怎麼寫 |
|---|---|
| 五向度起點值與現況 | 用期末報告第二項 |
| **對這個孩子有效的方法** | 格式 A 的紀錄。例：「限縮為 6 色後能在 20 秒內決定」 |
| **不要交接的** | 性格評價、家庭猜測、通報內容 |

# 十、保管與保密

| 項目 | 規定 |
|---|---|
| 一般觀察表 | 講師本人保管；不放在公共教師區 |
| **情緒單元（U08）紀錄** | **與一般紀錄分開存放**；僅限本人與單位主管閱覽 |

| 談論場合 | **只走正式管道**（導師、輔導室、主管）；不在休息室、群組、其他家長面前談論任何孩子 |

## 期中／期末檢視四問

**期中（建議 U09 後）**
1. 有沒有孩子五個向度**全部**停在起點值沒有變化？
2. 有沒有孩子某個向度出現**倒退**？→ **優先處理**
3. 有沒有孩子我到現在**寫不出任何一句具體描述**？→ 這不是孩子的問題，是我的

**期末（U12）**
4. 有沒有孩子已通報但尚未收到後續回覆？→ 主動向主管確認進度

> 每個班都會有一兩個「安靜到不會被記得」的孩子——
> 不吵不鬧、準時完成、從不求助。他們最容易被整個學期忽略。
> **發現自己寫不出他的事，就是最重要的發現。**

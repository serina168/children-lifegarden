# 材料採購總表｜Level 1 低年級

> **單價欄一律留白，由採購者填入當地實際價格。**
> 本表提供的是**規格、數量公式與採購時程**——這三項才是不會過期的部分。

**基準假設**：15 人班級・12 堂課・一學期
（人數不同時，用各表的公式重算，不要直接換算比例）

---

## 一、數量計算公式

```
消耗性材料：採購量 = 人數 × 每人份量 × 1.2（備品係數）＋ 講師示範 2 份
生鮮材料（花材）：採購量 = 人數 × 每人份量 × 1.3（損耗較高）＋ 講師示範 2 份
耐用教具：採購量 = 人數 ＋ 2（備品）
講師專用：1 套
```

**備品係數不可省略。** 12 堂課裡一定會有：紙破掉、筆斷芯、貼紙掉、
花瓣掉光、有人多拿一張。少了 20% 備品，你會在課堂上手忙腳亂。

## 七、成本彙總與控管

| 表 | 類別 | 性質 | 小計 |
|---|---|---|---|
| A | 耐用教具 | **一次投資**（3–5 年攤提） | |
| B | 自製教具 | 材料費低＋約 5.5 小時工時 | |
| C | 消耗性材料 | 每學期 | |
| D | 花材 | 單堂（U07） | |
| E | 成果展 | 每學期 | |
| | **首年總計**（A＋B＋C＋D＋E） | | |
| | **次年起**（B 部分補充＋C＋D＋E） | | |

**單人單堂成本試算**

```
單人單堂成本 =（C ＋ D ＋ E 小計）÷ 人數 ÷ 堂數
```

**建議控管方式**：先訂出每人每堂的材料費上限，再回頭調整規格。
可調整的順序（由影響小到大）：

1. 紙張磅數（C1 用一般磅數而非高磅）
2. 色鉛筆色數（36 → 24 色；但 U05 的選項數量對照表需一併調整）
3. 花材種類（改用樹葉或押花標本，成本可降 8 成以上）
4. 圓形紙（改由方形紙自行描圓裁下，省裁切費但多 5 分鐘課堂時間）
5. 粉彩（若教室清潔不便，可整項刪除，媒材縮為蠟筆＋色鉛筆）

**不建議刪減的項目**（刪了會影響教學品質或安全）

| 項目 | 為什麼不能刪 |
|---|---|
| 備品係數 1.2 | 課堂上臨時缺料會毀掉節奏 |
| 分割模板（B1） | 做歪或沒有，一整年的作品都會歪 |
| 過敏替代方案（D 表） | 這是安全問題，不是成本問題 |
| 放大鏡一人一支（A1） | 共用會讓觀察段從 12 分鐘拉長到 18 分鐘 |
| 圍裙（C29） | 弄髒衣服的抱怨，成本遠高於圍裙 |

# 引導語手冊｜Level 1 低年級

> 從十二個單元抽出、依**課堂情境**重編。
> 帶課時放在教學夾第一頁，卡住的時候翻開就有話可以說。

**使用原則（三句話）**
1. **問句代替評價，選項代替指示。**
2. **描述你看到的，不說出它的意義。**
3. **孩子停，你就停。**

## 4｜巡桌・一般回饋（三層回饋法）

**結構**：① 我看到你這裡＿＿ → ② 你＿＿，難怪＿＿ → ③ 你要不要＿＿？

**第一層・描述**（說不出來時，找這三個：數量／選擇／過程）

| 句子 | 出處 |
|---|---|
| 「我看到你這一排羽毛，一片一片排得很整齊。」 | U09 |
| 「你這一圈的點點，越外面越大。」 | U09 |
| 「你這裡有十二片花瓣。」 | U09 |
| 「你這一圈選了藍色。」 | U09 |
| 「你決定讓這裡空白。」 | U09 |
| 「你剛剛在這裡停了很久。」 ← **最有力的一句** | U09 |
| 「你剛剛擦掉重畫了一次。」 | U09 |

**第二層・指出行為**（必須是可以再做一次的動作，不是天分）

| 句子 | 出處 |
|---|---|
| 「你每畫一片就停下來看一下，難怪會這麼整齊。」 | U09 |
| 「你這一圈的間距很平均。你是先點了幾個點嗎？」 | U12 |
| 「你這個鱗片畫了三次，第三次的間距整齊很多。」 | U03 |

**第三層・邀請**（真問句，必須含「不要也可以」的空間）

| 句子 | 出處 |
|---|---|
| 「外面這一圈，你要不要也用同樣的方法？」 | U09 |
| 「這裡還有一塊空白，你想讓它空著，還是放點什麼？」 | U06 |
| 「這一圈你想重複，還是想變化？兩個都可以。」 | U01 |

## 12｜情緒課專用

> **四不**：不解讀・不追問・不轉述・不診斷。
> 純描述句是這一堂唯一安全的句型。

| 句子 | 出處 |
|---|---|
| **「你的快樂是黃色的。」**（純描述——本類最重要的句型） | U08 |
| 「你的生氣是紅色的，線很用力。」 | U08 |
| 「這一張你可以用力畫。生氣的時候本來就想用力。」 | U08 |

| 「你想說說看嗎？不想說也可以。」 | U08 |

## 16｜界線・必背三句

> **結構固定：說事實 → 表明界線 → 指路。**
> 三句都要能不看稿說出。這是 U08 的必過項。

**① 家長問：「他畫這樣代表什麼？」**
> 「畫面本身沒辦法告訴我們孩子的心理狀態，顏色跟線條受很多因素影響。
> 我可以告訴您我在課堂上實際看到的：他今天畫得很專心，而且完成了。
> 如果您對他最近的狀況有疑慮，跟導師或輔導老師談會比較適合。」

**② 孩子說了一半又不說**
> 「好，你想說的時候再說。我在這裡。」
> （然後**真的走開**，不要停在旁邊等他繼續。）

**③ 同事問：「那個孩子是不是家裡有問題？」**
> 「我在課堂上看到的部分，我已經跟導師反映了。其他的我不太清楚。」

**④ 家長問：「你們是不是在做心理輔導？」**（U08 加考題）
> 「不是。我們做的是美術課。今天教的是用線條和顏色表現不同的感覺，這是繪畫的技法。
> 我不會分析孩子的畫，也不會做任何心理判斷，那需要專業訓練，不是我的範圍。
> 如果您對孩子的情緒狀況有疑慮，學校輔導室或兒童心智科會是更適合的資源。」

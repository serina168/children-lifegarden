# 通用篇（三版共同）

## 一、開課前必辦（缺一不可）

| # | 事項 | 時間 | 未完成的後果 |
|---|---|---|---|
| 1 | 回收家長調查表（過敏：花粉／香味／乳膠／接觸性） | 開課前 1 週 | **U07 花朵課不可開課** |
| 2 | 回收肖像與作品使用同意書 | 開課前 1 週 | 不可拍照、不可展示 |
| 3 | 核對過敏名單，備妥替代材料 | 開課前 1 週 | 同第 1 項 |
| 4 | 確認急救箱位置與內容 | 每學期 | — |
| 5 | 確認逃生動線、滅火器位置 | 每學期 | — |
| 6 | 確認緊急聯絡流程（主管、家長、119） | 每學期 | — |
| 7 | 確認教室通風方式（窗、抽風） | 每學期 | 使用溶劑類材料時不可開課 |

## 二、每堂課的三次人數清點

| 時機 | 為什麼 |
|---|---|
| 開課時 | 確認到課人數與名單一致 |
| 中場 | 抓出離座未歸的孩子 |
| 下課前 | 確認全員在場才放學 |

**任何孩子離開教室超過 5 分鐘，必須有人知道。**
超過 10 分鐘且去向不明 → 立即通知單位主管，不待課後。

**預防制度**（擇一）
- 離座通行證：每人 2 張，出去前放在桌上（一眼看出誰不在）
- 離座板：出去前掛牌

## 三、緊急狀況通則

```
發生任何意外時的順序：

① 安全　→　② 情緒　→　③ 責任　→　④ 解決方案
```

**順序顛倒，兩個孩子都會受傷。**

範例（打翻顏料）：
1. **安全**：顏料離地、避免踩滑
2. **情緒**：看被弄髒的孩子，「你很難過，這一塊被蓋住了。」（先承認損失）
3. **責任**：「我看到你的手肘撞到了。去拿抹布來，我們一起處理。」（給任務，不給指責）
4. **解決**：「這一塊我們可以變成什麼？湖水？雲？還是換新的紙？」

## 四、講師不可獨自處理的三種情形

| 情形 | 做什麼 |
|---|---|
| 孩子離開教室去向不明 | 請鄰近成人協助查看，**自己留在教室**（不可讓 15 個低年級獨處） |
| 需送醫的傷害 | 立即通知主管；由第二位成人陪同送醫；講師留在教室 |
| 過敏反應加重（呼吸急促、大面積紅疹） | **立即通知主管與家長**；準備送醫；不自行給藥 |

# A 版｜平面課安全守則（Level 1 全部）

> 適用單元：L1 全部（U01–U12）、L2 的平面單元

## A-1 材料規格紅線（採購時即須確認）

| 品項 | 紅線 | 為什麼 |
|---|---|---|
| 粗桿蠟筆 | **直徑 > 1 公分** | 防誤吞 |
| 圓形貼紙 | **直徑 > 1.5 公分** | 防誤吞 |
| 廣告顏料 | **無毒、可水洗、有安全標示** | — |
| 麥克筆 | **水性、無臭** | 溶劑型不可用於密閉教室 |
| 代針筆 | **筆蓋有透氣孔** | 防誤吞窒息 |
| 剪刀 | **圓頭安全款** | — |
| 圓規 | **鈍頭安全款**（非尖針） | — |
| 描邊物件 | **非玻璃、無缺口毛刺** | — |
| 模板卡紙 | V 形凹口邊緣**已修圓** | 防割手 |
| 花材 | **非有毒植物**；玫瑰**已去刺** | 禁用夾竹桃、黃金葛、聖誕紅、彩葉芋 |

## A-2 工具使用規範

| 工具 | 規範 | 首次出現 |
|---|---|---|
| **代針筆** | 開課前統一收走筆蓋，改為「用完插回筆筒」；不可含在嘴裡 | U03 |
| **削鉛筆機** | 固定放在教室同一角落，一次一人，不可帶回座位 | U03 |
| **橡皮擦屑** | 每桌一個小紙盒；**不可用嘴吹**（會吹到隔壁眼睛） | U03 |
| **色鉛筆** | 削尖後尖端銳利，不可指向他人；斷芯立即更換，不讓孩子自行拔芯 | U05 |
| **剪刀** | 圓頭安全剪；**裁圓形紙、挖窗式外框由講師事前完成** | U11 |
| **圓規** | 低年級**原則不發**。小二下依三判準開放：①小二下 ②紋樣穩定 ③有容錯策略。<br>使用時：鈍頭款、墊墊板、收納時針腳朝內夾緊 | U04 |
| **放大鏡** | **不可用於直射陽光**（聚焦會起火）；避免在窗邊使用 | U07 |
| **木夾** | 檢查有無彈簧夾手；小一由講師示範夾法 | U11 |

## A-3 材料安全

| 材料 | 規範 |
|---|---|
| **油性粉彩** | 務必穿圍裙；桌面鋪報紙；**提醒不可揉眼睛**；課後洗手（粉末殘留指縫） |
| **廣告顏料** | 每桌一份，不放桌緣；翻倒後地面立即擦乾（防滑倒）；常備抹布 3 條 |
| **棉花棒** | 使用後統一回收；不可含在嘴裡；**不可戳眼睛與耳朵** |
| **口紅膠／白膠** | 一組一份，用完立刻蓋回；提醒不可塗在手上玩 |
| **花材／葉片** | 「可以摸、可以聞、可以翻背面。不可以撕、不可以放進嘴巴。」<br>使用前沖洗瀝乾；課後全班洗手 |
| **高磅紙（U08）** | 允許用力畫的單元須用 150 g 以上；備妥背面補紙用的膠帶；桌面鋪墊板 |
| **氣味** | 若孩子對粉彩或麥克筆氣味明顯不適，**立即改用色鉛筆並保持通風**，同時記錄 |

## A-4 空間與動線

| 項目 | 規範 |
|---|---|
| 材料站 | 至少 3 個（每站服務不超過 5 人）；**不可全班同時起身拿材料** |
| 走動路線 | 單向環形，全班同方向；不經過洗手台或垃圾桶前方 |
| 走動觀摩 | 限定單一方向繞行；講師站在動線末端；作品排圈時留足走道，提醒不可踩 |
| 地面 | 材料籃、包包不可放地面走道 |
| 掛展（U11） | 麻繩高度 120–130 公分（伸手可及，**不可站椅子**）；<br>**不可綁在消防設備、電線、逃生標示上**；不可擋逃生動線；須取得場地管理者同意 |
| 上前操作 | 一次最多 3 人（如 U10 拼組、U11 掛展） |

## A-5 過敏處理 SOP（以花粉為例）

```
發現孩子打噴嚏、揉眼、眼睛發紅

① 立即移走該生的花材，放到教室另一端
② 請他去洗手、洗臉
③ 開窗通風
④ 給替代材料（照片卡／塑膠花／用觀察紙繼續）
⑤ 課後主動聯絡家長，告知經過與處置
⑥ 下堂課前確認狀況，該堂起備妥替代方案

　※ 反應加重（呼吸急促、大面積紅疹）→ 立即通知主管與家長，準備送醫
```

**這不是需要判斷的情境，是需要立刻執行的 SOP。**
最佳解其實在開課前就完成了——家長調查表的過敏欄位。

## A-6 身心安全（與生理安全同等重要）

| 項目 | 規範 | 依據 |
|---|---|---|
| **不排名、不評分、不張貼「最佳作品」** | 全系列底線 | U03・U09・U11 |
| **退出權** | 孩子有權不展示、不拍照、不導覽、不發言，**且不需要說明理由**。<br>課堂上要明講一次，讓孩子知道自己有這個權利 | U11 |
| **不公開朗讀私密書寫** | U07⑦「花在等什麼」、U08⑥「想跟老師說的話」——不朗讀、不轉述、不引用於家長訊息，除非事先徵得孩子同意 | U07・U08 |
| **不心理解讀** | 不從畫面推測心理，不對孩子、家長、同事說任何「這代表……」 | 全系列 |
| **不使用診斷詞彙** | 過動、焦慮、憂鬱、自閉、發展遲緩 | 全系列 |
| **不評論孩子的身體或能力** | 不說「你手很笨」「沒有美感」；只調整工具，不評論他的手 | U03 |
| **不使用連坐處罰** | 「因為有人吵所以全班不能……」 | U10 |
| **不強迫適應** | 對材料有感官排斥的孩子，只調整材料，不要求適應，不在其他孩子面前說明原因 | U05・U07 |

## A-7 通報時機（三種情形，1 次出現即通報）

```
① 孩子主動描述被傷害的經過，或身上出現非意外性傷痕
② 孩子表達不想活、想消失、想傷害自己
③ 孩子透露長時間無人照顧、沒有食物、獨自在家過夜

　　　↓ 24 小時內

① 當下：維持平常反應，不追問，不表現震驚
② 課後立即：書面記錄（時間、地點、在場者、孩子的原話、你的處置）
③ 24 小時內：通報單位主管 ＋ 學校輔導室
④ 後續：依指示配合，不自行聯絡家長、不自行調查
```

**當堂即處理（不待課後）**
- 自傷動作（打自己、戳自己、咬）→ 停止創作、確保安全、同日反映導師
- 攻擊他人（推、打、丟東西）→ 當下停止、帶離冷靜、同日反映導師與家長
- 離開教室去向不明 > 10 分鐘 → 立即通知主管

**不做的事**：不聯絡家長詢問、不告訴其他家長、不在教師群組討論、
**不把孩子的作品當作證據附上**、不在孩子面前表現任何異樣。

# B 版｜複合媒材課安全守則（Level 2・暫定版）

> 依 02 系列大綱建置（U05 自然觀察、U06 複合媒材、U09 分組合作）。
> **待 L2 講義完成後須複核並補充。**

## B-1 承接 A 版全部

平面課的所有規範在複合媒材課**同樣適用**，以下為**增列**項目。

## B-2 新增材料的安全

| 材料 | 規範 |
|---|---|
| **紙材**（色紙、包裝紙、雜誌、棉紙） | 檢查有無訂書針、金屬扣；雜誌避免不適齡內容 |
| **輕黏土** | 確認無毒標示；提醒不可入口；有麵粉／小麥過敏者需確認成分 |
| **毛線、鈕扣** | **鈕扣直徑 > 1.5 公分**（防誤吞）；小顆珠飾不建議中年級以下使用 |
| **亮片、金蔥** | 極易散落且不易清除；限定在托盤內操作；**不可靠近眼睛**；課後徹底清潔 |
| **白膠** | 無毒可水洗款；一組一份；提醒不可塗在手上撕著玩 |
| **熱熔膠** | **中年級不使用**。必要時由講師代為操作，孩子不得觸碰 |
| **乾燥植物** | 同 A 版花材規範；確認無黴、無蟲；過敏者使用替代品 |
| **各式膠帶** | 檢查切割器邊緣；由講師預先撕好或使用安全切台 |

## B-3 戶外採集（L2-U05）

| 項目 | 規範 |
|---|---|
| 事前 | **書面風險評估**；家長知會；確認路線與集合點 |
| 人力 | 至少 2 位成人；學生 ≤ 15 人 |
| 攜帶 | 急救箱、飲水、手機、學生名單、家長聯絡清單 |
| 採集規範 | 只撿落葉落花，**不折枝、不採整株**；不進入私人土地與保護區 |
| 植物辨識 | **講師事前勘查路線**，標出有毒或有刺植物；孩子不觸碰不認識的植物 |
| 蚊蟲 | 事前提醒穿長袖；備防蚊液（**確認無過敏後才使用**） |
| 人數清點 | 出發、中途、返回各一次 |
| 天氣 | 高溫、雷雨、空品不良時取消，改為室內替代方案 |

## B-4 分組合作的安全（L2-U09）

| 項目 | 規範 |
|---|---|
| 作品衝突 | 「他畫壞我的區塊」——**先修復作品（給選擇權），再處理人（私下）** |
| 材料共用 | 每組材料明確分配；剪刀等工具一人一支，不共用 |
| 走動 | 大圓共作時，一次最多 3 人上前 |
| 情緒 | 分組會放大比較與排擠；**不公開評比組別**，不設「最佳小組」 |

## B-5 情緒單元（L2-U03）

**與 L1-U08 相同的四不原則**：不解讀、不追問、不轉述、不診斷。

**三個必做**
1. 分享圈三規則每次完整唸一遍
2. 課程順序**以平靜收尾**，不以負面情緒結束課堂
3. 觀察紀錄**與一般紀錄分開存放**，僅限本人與主管閱覽

**資格限制**：L1-U08 的必過項（三句標準回應、八題演練、通報流程）
**未通過者不得帶 L2-U03**。

# C 版｜立體與木器課安全守則（Level 3・暫定版）

> 依 03 系列大綱建置（U05 木器與塗料、U06 燈具鏡框捕夢網）。
> **待 L3 講義完成後須複核並補充。**
> 本版的風險等級明顯高於 A、B 兩版，**每一項紅線都不可因時間壓力放寬**。

## C-1 承接 A、B 版全部

## C-2 八項紅線（L3-U06 明定）

| # | 紅線 | 說明 |
|---|---|---|
| 1 | **禁止 110V 電源改裝** | 燈具**只用 LED 電池組**；不得接市電、不得改裝插頭 |
| 2 | **美工刀由講師操作** | 孩子不使用美工刀、切割器、裁紙機 |
| 3 | **熱熔膠由講師操作** | 高年級亦然；孩子不觸碰膠槍與熔膠 |
| 4 | **玻璃邊緣須事前處理** | 鏡面、玻璃的邊緣須包邊或磨圓；破損品立即撤除 |
| 5 | **電動工具僅講師使用** | 電鑽、砂輪機等；孩子不在場或保持安全距離 |
| 6 | **溶劑與亮光漆須通風** | 開窗＋抽風；不可在密閉教室使用；標示須為低 VOC／水性優先 |
| 7 | **不使用尖銳金屬件** | 鐵絲末端須折彎收邊；圖釘、大頭針不發給孩子 |
| 8 | **不獨自操作** | 任何涉及工具、塗料、電器件的步驟，孩子不得在無成人視線範圍內進行 |

## C-3 木器與塗料

| 項目 | 規範 |
|---|---|
| **木料** | 確認無毛刺、無裂痕；邊角須磨圓（講師事前完成） |
| **砂紙打磨** | 戴口罩；在通風處或戶外；粉塵不可吹（用刷子或濕布清） |
| **壓克力顏料** | 無毒標示；乾後不可撕食；沾到皮膚立即清洗 |
| **亮光漆／保護漆** | **水性優先**；由講師上漆或在戶外／通風處進行；乾燥期間作品不放教室 |
| **點畫筆（dotting tools）** | 檢查尖端；不可指向他人 |
| **乾燥時間** | 排入教案時間表；**不可為趕進度而縮短**（未乾的漆會沾手沾衣） |
| **圍裙與口罩** | 木器課一律穿圍裙；打磨與噴漆時戴口罩 |

## C-4 電器件（小夜燈）

| 項目 | 規範 |
|---|---|
| 電源 | **僅限 LED 電池組**（3V／4.5V）；**嚴禁 110V 改裝** |
| 電池 | **鈕扣電池嚴禁使用**（誤吞會造成嚴重灼傷）；使用 3 號／4 號電池 |
| 電池盒 | 須有螺絲固定蓋，孩子不可自行開啟 |
| 發熱 | LED 應為低發熱型；成品不可長時間密閉點亮 |
| 線材 | 不得裸露；接點須絕緣處理（由講師完成） |
| 帶回家 | 附上**家長注意事項卡**：使用時長、電池更換由家長操作、不可拆解 |

## C-5 捕夢網與編織

| 項目 | 規範 |
|---|---|
| 金屬圈 | 檢查接縫，包上布或膠帶 |
| 鐵絲 | 末端**一律折彎收邊**，由講師檢查後才發下 |
| 羽毛 | 確認來源與清潔；**羽毛過敏者須有替代方案**（布條、緞帶） |
| 繩線 | 長度不超過 50 公分（避免纏繞頸部）；不可套在脖子上玩 |

## C-6 時鐘機芯

| 項目 | 規範 |
|---|---|
| 機芯安裝 | 由講師完成軸心穿孔與固定 |
| 指針 | 金屬指針邊緣須確認不銳利 |
| 電池 | 同 C-4；不使用鈕扣電池 |

## C-7 高年級的身心安全

| 項目 | 規範 | 依據 |
|---|---|---|
| **自傳式創作的保密** | 故事曼陀羅、個人符號系統會涉及真實生命經驗。<br>**不公開朗讀、不轉述、不作為教學範例**，除非事先取得孩子明確同意 | L3-U03・U04 |
| **青春期前的自我議題** | 「我畫得比別人差」「這個很幼稚」——用不評價的深度提問回應；<br>知道**何時轉介**（持續自我貶低、行為明顯改變） | L3-U08 |
| **展覽的同意** | 作品論述會寫出個人故事；**展出前逐件確認孩子是否同意公開** | L3-U10 |
| **講師自我照顧** | 高年級的深度議題會消耗講師。<br>建立督導或同儕支持機制，**不獨自承擔** | L3-U08 |

## 給講師的最後三句

1. **紅線不因時間壓力放寬。** 課上不完可以下次補，受傷不能。
2. **先安全、再情緒、再責任、最後解決方案。** 順序顛倒，兩個孩子都會受傷。
3. **身心安全和生理安全一樣重要。** 一句錯誤的心理解讀，可能跟著孩子好幾年。

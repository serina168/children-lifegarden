# 學習單總集｜Level 1 低年級

> 12 張，每單元一張。A4 單面，可直接影印。

## 共同版面規範

| 項目 | 規格 |
|---|---|
| 紙張 | A4 直式 |
| 邊界 | 四周 1.5 公分 |
| 字級 | **16pt 以上**（標題 20pt） |
| 字體 | 標楷體或圓體（低年級易辨識） |
| 橫線高度 | 1.2–1.5 公分（低年級字大） |
| 畫框 | 最小 4×4 公分 |
| 色塊方格 | 最小 2×2 公分（要塗得進去） |
| 印刷 | 單色黑白即可；碳粉濃度調低，避免蓋過孩子的筆跡 |

## 三個設計原則

1. **勾選 ＞ 書寫。** 低年級寫字慢，能勾就不要寫。
2. **每一張都有「可以不寫」的選項。** 退出權要印在紙上，不能只是口頭說。
3. **問「你怎麼想」，不問「畫得好不好」。** 學習單不是評量表。

# 08｜今天的心情是什麼顏色（U08）

```
┌──────────────────────────────────────────┐
│  今天的心情是什麼顏色                                    │
│  姓名 ____________     日期 ____ / ____                 │
│                                                          │
│  ① 今天我比較像（圈起來，也可以圈「說不出來」）           │
│      快樂  生氣  難過  平靜                              │
│      緊張  害怕  興奮  孤單    說不出來                  │
│                                                          │
│  ② 我的身體現在（打勾）                                  │
│      肚子：□ 暖暖的　□ 緊緊的　□ 沒感覺                 │
│      肩膀：□ 鬆鬆的　□ 硬硬的　□ 沒感覺                 │
│                                                          │
│  ③ 我的三張畫，用的顏色是                                │
│      快樂 → □（塗色）    生氣 → □    平靜 → □           │
│                                                          │
│  ④ 我的線條（圈起來）                                    │
│      快樂的線：圓的 / 尖的 / 直的 / 彎的                 │
│      生氣的線：圓的 / 尖的 / 直的 / 彎的                 │
│      平靜的線：圓的 / 尖的 / 直的 / 彎的                 │
│                                                          │
│  ⑤ 畫完以後，我覺得（圈起來）                            │
│      比較輕鬆了　　沒什麼不一樣　　還是有點悶            │
│                                                          │
│  ⑥ 我想跟老師說一句話（可以不寫）                        │
│      ____________________________________                │
└──────────────────────────────────────────┘
```
**設計說明**
- ①「說不出來」與其他選項**同樣大小**——它是正當選項，不是逃避。
- ⑤問的是**畫完的感覺**，不是「你為什麼有這個心情」。前者是課程效果，後者是隱私。
- ⑥「可以不寫」四個字**必須印出來**。此欄若出現需通報內容，依通報流程處理；
  若只是一般心事，不公開、不轉述、不引用於家長訊息。

# 09｜作品分享圈（U09）

```
┌──────────────────────────────────────────┐
│  作品分享圈                                              │
│  姓名 ____________     日期 ____ / ____                 │
│                                                          │
│  ① 我看別人的畫（選兩張，寫下你看到什麼）                 │
│      第一張：我看到 ______________________               │
│      第二張：我看到 ______________________               │
│                                                          │
│  ② 我想問的問題                                          │
│      我想問 ________：______________ 是怎麼畫的？        │
│                                                          │
│  ③ 有人問我問題嗎？                                      │
│      □ 有，他問我：____________________                  │
│      □ 沒有                                              │
│                                                          │
│  ④ 今天別人跟我說的話裡面，我最喜歡的一句                 │
│      「_______________________________」                 │
│                                                          │
│  ⑤ 今天我（可複選）                                      │
│      □ 說了話　□ 沒說話但有聽　□ 去看了別人的畫          │
│      □ 讓別人看了我的畫　□ 學到一個新方法                │
└──────────────────────────────────────────┘
```
**設計說明**
- ③的「沒有」要印得跟「有」一樣大——沒被問到不是失敗。
- ⑤把「沒說話但有聽」列為正式選項，與「說了話」並列。
  **安靜的參與也是參與**，這一欄是給不發言的孩子的位置。

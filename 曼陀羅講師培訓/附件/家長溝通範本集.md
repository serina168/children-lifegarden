# 一、三條溝通原則

## 原則 1：只說行為與變化，不說原因與判斷

| ✅ | ❌ |
|---|---|
| 「這三堂課他開始不問我就自己選顏色了。」 | 「他比較沒有安全感，所以需要一直確認。」 |
| 「他今天畫了三十分鐘沒有離開座位。」 | 「他今天特別專心，心情應該不錯。」 |
| 「他發現花瓣背面顏色比較淺，主動翻過來給同學看。」 | 「他觀察力很好，很聰明。」 |

## 原則 2：第二段必須是「只有在場的人才寫得出來」的東西

一則課後訊息三段：
```
① 今天做了什麼（客觀，1–2 句）
② 我看到什麼（具體到某個行為）　← 整則訊息的價值所在
③ 回家可以怎麼聊（給一個問題，不給評語）
```

**判斷第②段好壞的唯一標準**：這句話能被替換成班上任何一個孩子嗎？
可以，就是通用句，重寫。

## 原則 3：公開的統一，個別的私訊

| 內容 | 管道 | 原則 |
|---|---|---|
| 全班作品照 | 群組 | **全班統一、定期**（如每兩週），不挑選 |
| 個別觀察訊息 | **私訊** | 輪流覆蓋，一學期每人至少 2–3 次 |
| 課堂狀況（衝突、情緒事件） | 私訊或面談 | **不在群組**；只描述行為，不描述動機 |
| 孩子的私密書寫 | **不傳** | 除非事先問過孩子並得到同意 |

**在公開空間做不平均的事，一定會出事。**

# 二、開課通知

```
【{課程名稱} 開課通知】

{家長姓名} 您好，我是 {班級} 的曼陀羅課老師 {講師姓名}。

▍課程是什麼
曼陀羅這個字來自古印度，原意就是「圓」——從一個中心點出發、
一圈一圈往外長的對稱圖案。大自然裡到處都是：花心、雪花、
蜘蛛網、切開的柳丁，都是天然的曼陀羅。

▍孩子會練習三件事
1. 持續專注十五分鐘完成一個段落
2. 自己做決定——畫什麼、用什麼顏色，都由他決定，老師不給標準答案
3. 把一件事從頭做到完，並且願意拿給別人看

▍課程內容
繪畫技法與色彩：對稱、重複、配色、觀察。
**不涉及任何宗教內容，也不會做心理分析或情緒治療。**
如果孩子在課堂上有需要特別留意的狀況，我會直接跟您和導師反映，
但我不會替孩子的畫作做心理解讀，那不是我的專業範圍。

▍時間與作品
共 {N} 堂，每堂 {90} 分鐘，會完成 {8} 件作品。
所有作品畫在直徑 20 公分的圓形畫布上，期末會裱好帶回。
期末我們會辦一個小型的成果展。

▍需要您協助的三件事
1. 填寫附上的「家長調查表」（過敏與材料，**務必填寫**）
2. 簽署「肖像與作品使用同意書」
3. 上課請穿舊衣或準備圍裙（會用到蠟筆、粉彩、顏料）

▍聯絡方式
{講師聯絡方式}　　{可聯絡時段}

期待和孩子一起開始。

{講師姓名}
{日期}
```

```
　1. 花粉過敏　　　　　□ 無　□ 有，症狀：____________
　2. 香味／氣味敏感　　□ 無　□ 有，對：____________
　3. 乳膠過敏　　　　　□ 無　□ 有

　5. 其他需注意事項：____________________________

二、慣用手　□ 右　□ 左　□ 不確定

三、孩子的繪畫經驗
　□ 沒有上過美術課
　□ 上過（多久：______），課程類型：____________
　□ 在家常畫畫
　□ 在家不太畫畫

四、您最希望孩子從這門課得到什麼？（可複選）
　□ 專注力　□ 表達自己　□ 創意　□ 完成一件事的經驗
　□ 交朋友　□ 技巧進步　□ 其他：____________

　____________________________________________

```

**第四題的用途**：這是家長的期待。
若家長勾「技巧進步」而課程重點是「敢開始」，你要在第一次課後訊息就**主動說明差異**，
不要等到期末才發現雙方看的東西不一樣。

**第五題的用途**：有些家長會在這裡寫出重要訊息（家庭變動、孩子的特殊狀況）。
**讀了就好，不追問，不轉述**，只在需要時調整教學。

# 四、課後訊息 ×6

> 六種第②段的素材類型。**輪流使用**，不要每次都寫同一種。
> 一則不超過 150 字。

## 範本 1｜素材：一個「第一次」

```
{孩子姓名} 的家長您好：

今天的主題是「幫作品穿衣服」，孩子替自己的畫做了外框、取了名字，
也寫了說明卡，然後掛到走廊的展線上。

今天我特別想告訴您：{孩子姓名} 這學期第一次自願當導覽員，
向兩位客人介紹了自己的作品，三句話都說完了。前幾堂他都是選擇「聽就好」。

走廊的展覽會掛到 {日期}，接送時可以帶他去看，
也可以問他：「你當導覽員的時候說了什麼？」

{講師姓名}
```

## 範本 2｜素材：介入 → 反應

```
{孩子姓名} 的家長您好：

今天的主題是「幫作品穿衣服」……

今天我特別想告訴您：{孩子姓名} 本來說「我的很醜不要掛」。
我給了他四個選擇，包括「今天先不掛」。他想了一下，選了「掛在角落」。
掛完之後，他在展線前站了一分鐘看著自己的畫。

我覺得那一分鐘很珍貴。回家可以問他：「你的畫掛在哪裡？」

{講師姓名}
```

## 範本 3｜素材：跨時間比較

```
{孩子姓名} 的家長您好：

今天的主題是「幫作品穿衣服」……

今天我翻了一下這學期的紀錄，想跟您分享一個變化：
第一堂課，{孩子姓名} 從老師說完到開始下筆，等了五分鐘。
最近三堂，他都是不到兩分鐘就開始了。

畫得漂不漂亮我不太看，但「敢開始」這件事，我覺得比什麼都重要。

{講師姓名}
```

## 範本 4｜素材：一個具體的觀察時刻（自然觀察課）

```
{孩子姓名} 的家長您好：

今天的主題是「花的祕密——花朵曼陀羅」。孩子練習用「觀察四問」看一朵真花：
形狀、紋路、對稱、重複，然後從中心的花心一層一層往外畫出花瓣。

今天我特別看到 {孩子姓名}：他發現花瓣的背面顏色比正面淺，
還主動翻過來給旁邊的同學看。

回家可以問他：「你在花的背面發現了什麼？」

另外，今天用的是 {花材名稱}。如果孩子回家後有打噴嚏、皮膚癢的情形，
請告訴我，我下次會準備替代材料。

{講師姓名}
```

## 範本 5｜素材：處理錯誤的方法（容錯）

```
{孩子姓名} 的家長您好：

今天的主題是「夜晚的守護者——我的貓頭鷹」。孩子練習把動物簡化成
三個特徵，然後從中心的臉往外畫羽毛和裝飾。

今天我想跟您分享一件事：{孩子姓名} 的兩隻眼睛畫得一大一小，
他自己發現了。他沒有換紙，也沒有塗掉，而是在小的那一隻外面加了一圈羽毛，
讓兩隻變一樣大。

這個方法是他自己想到的。我把它介紹給全班了。

回家可以問他：「你的貓頭鷹叫什麼名字？牠現在在做什麼？」

{講師姓名}
```

## 範本 6｜素材：孩子自己的決定（給「安靜型」的孩子）

```
{孩子姓名} 的家長您好：

今天的主題是「顏色的家族」。孩子練習用三步驟決定整張畫的顏色：
先選主角的顏色，再選旁邊的，最後灑一點點綴色。

今天我特別看到 {孩子姓名}：他整張都用藍色系。我問他是不是故意的，
他說「對，因為我想讓它像晚上」。他很清楚自己要什麼，
而且從頭到尾沒有改過。

回家可以問他：「你的主角為什麼選那個顏色？」

{講師姓名}
```

> **範本 6 特別重要。** 班上總有幾個不吵不鬧、準時完成、從不求助的孩子，
> 他們最容易一整個學期都沒有被寫進任何一則訊息。
> **每三堂檢查一次：這學期我寫過誰？**

# 五、難題回應 ×10

> 家長最常問的十句。前四句建議**背到不用想**。

## ★ 1. 「他畫這樣代表什麼？」

> 「畫面本身沒辦法告訴我們孩子的心理狀態，顏色跟線條受很多因素影響。
> 我可以告訴您我在課堂上實際看到的：他今天畫得很專心，而且完成了。
> 如果您對他最近的狀況有疑慮，跟導師或輔導老師談會比較適合。」

**結構**：說事實 → 表明界線 → 指路。這個結構三句必背都適用。

## ★ 2. 「你們是不是在做心理輔導？」

> 「不是。我們做的是美術課。今天教的是用線條和顏色表現不同的感覺——
> 快樂的線比較圓、生氣的線比較尖，這是繪畫的技法。
> 我不會分析孩子的畫，也不會做任何心理判斷，那需要專業訓練，不是我的範圍。
> 如果您對孩子的情緒狀況有疑慮，學校輔導室或兒童心智科會是更適合的資源。」

**要答得乾脆。** 任何「有一點」「算是啦」的回答，都會讓家長對課程性質產生誤解。

## ★ 3. 「這個曼陀羅是不是宗教的東西？」

> 「這個問題很多家長都會問。曼陀羅這個字來自古印度，原意就是『圓』。
> 世界各地都有圓形對稱的圖案，像雪花、花心、蜘蛛網都是。
> 我們的課程只教繪畫的部分——對稱、重複、配色，不會有任何宗教內容。
> 您如果想看，我可以給您這學期的課程大綱。」

**三段式**：承認問題合理 → 一句話定義 → 明確說出不會做什麼。最後主動提供大綱。

## ★ 4. 「他有沒有進步？」／「他畫得好不好？」

> 「我不用『好不好』來看，因為那是我的標準，不是他的。
> 我看的是他自己跟自己比——第一堂課他要等五分鐘才敢下筆，現在兩分鐘就開始；
> 以前畫錯就換紙，現在他會自己修好。
> 這兩件事，我覺得比技巧重要，因為技巧會自己長出來，
> 但『敢開始』和『不怕犯錯』是要練很久的。
> 如果您想看技巧，我可以指給您看他這學期線條的變化——
> 您看第一張跟最後一張的間距。」（拿作品對照）

**關鍵在最後一段**：用作品的實際對照滿足家長對技巧的關心，立場不必退讓。

## 5. 「他怎麼都用同樣的顏色？是不是有什麼問題？」

> 「我理解您會注意到這個。不過在課堂上，顏色的選擇跟很多事有關——
> 今天離他最近的是哪支筆、上一堂看到什麼、最近喜歡什麼卡通。
> 我不會從顏色去判斷孩子的心情，那不是我的專業，也不準。
> 我可以告訴您我實際看到的是：他這三堂都很快就決定好顏色，中途沒有改，
> 而且每一張都塗完了。這代表他很清楚自己要什麼。
> 如果您對他最近的狀況有疑慮，我建議跟導師或輔導老師聊聊會更適合。」

## 6. 「他在家都不畫，是不是不適合上這種課？」

> 「在家不畫是很常見的。這個年紀的孩子，畫畫需要一個『被安排好的環境』——
> 桌上東西收乾淨、材料擺出來、有人坐在旁邊。
> 這些條件在教室裡我們幫他準備好了，在家裡他自己做不到。
> 如果您想在家試試看，不用要求他畫完整一張，
> 準備一張紙和三支筆放在桌上就好，不催他，通常一兩天內他會自己坐下來。」

## 7. 「摺紙就摺紙，這樣算美術課嗎？」

（把作品拿起來對摺給家長看）
> 「您看，他自己摺出八等分，兩邊幾乎對稱——這是他自己做到的，不是我畫給他的。
> 今天學的是『先找到中心，再往外長』，下禮拜的貓頭鷹、期末的生命樹，
> 都要用今天這個方法。這張是地基。」

**當場對摺一次，比說十句「這是基本功」有效。**

## 8. 「為什麼我孩子的畫沒有拍給我？」

> 「不好意思，這次是隨機挑幾張，這樣的確不公平。
> 從下週開始我改成——每兩週把全班作品拍成一份，統一傳到群組，
> 每個孩子都會有。」

**改制度，不是補救個案。** 然後真的做到。

## 9. 「可以幫我孩子的作品多拍幾張／放在成果展最中間嗎？」

> 「我理解您希望孩子的努力被看見，這件事我也很在意。
> 我們的做法是每個孩子都一樣——全班的作品都會拍、都會展，位置是照號碼排的。
> 不過我可以做另一件事：我會把 {孩子姓名} 在課堂上的一些具體表現寫給您，
> 那些是照片上看不到的。比如上禮拜他……」（接一句真實的觀察）

**用制度擋掉特權，用觀察滿足需求。**

## 10. 「他上課有沒有乖？」

> 「他今天在座位上待了三十分鐘，中間起來兩次去拿材料。
> 我不太用『乖不乖』來看孩子，因為安靜不一定代表在學。
> 我看的是他有沒有在畫、卡住的時候會不會找辦法。今天這兩件他都有。」

**把「乖」的框架換掉。** 不然家長會開始要求孩子在美術課「不要動」。

# 六、成果展邀請

```
【{展名} — {班級} 曼陀羅作品展】

{家長姓名} 您好：

這學期的作品完成了。孩子們替自己的畫做了外框、取了名字，
也寫了說明卡，全部掛在 {地點}。

▍展期
{開始日期} — {結束日期}
{可參觀時段}

▍地點
{詳細地點與如何抵達}

▍怎麼看比較好
1. 先找到孩子自己的那一張（他知道在哪裡）
2. 讀一下說明卡——「我最喜歡這裡」那一行是他自己寫的
3. 請孩子當導覽員。他練習過三句話：
　　「這是我的作品，它叫做＿＿」
　　「我最喜歡的是＿＿這個地方」
　　「這裡是用＿＿畫的」

▍一個小小的請求
看孩子的作品時，如果可以，請先問他：「你最喜歡哪裡？」
再說您的想法。這個順序，對孩子的意義很不一樣。

▍作品什麼時候帶回
{撤展日期} 撤展後，作品會裱好發還。

謝謝您這學期的支持。

{講師姓名}
```

**「一個小小的請求」那一段不要刪。**
多數家長看到作品的第一句是「好漂亮」或「這裡怎麼歪歪的」，
一句提醒就能讓孩子的展覽經驗完全不同。

# 八、群組與私訊的分流政策

> 建議在開課通知中就寫明，避免後續爭議。

| 內容 | 群組 | 私訊 | 面談 |
|---|---|---|---|
| 課程通知、材料準備 | ✅ | | |
| 全班作品照（定期、統一） | ✅ | | |
| 展覽資訊 | ✅ | | |
| 個別觀察訊息 | ❌ | ✅ | |

| 孩子的私密書寫 | ❌ | ❌ | ❌ |

## 三條群組規則（自己遵守）

1. **不在群組提任何單一孩子的名字**（除了公開表揚全班）
2. **作品照要嘛全班都有，要嘛都不發**
3. **不在群組回答個別問題**——回一句「我私訊跟您說」就好

## 頻率建議

| 項目 | 頻率 |
|---|---|
| 全班作品照 | 每兩週一次（12 堂約 6 次） |
| 個別觀察訊息 | 每堂 3–5 人輪流，一學期每人 2–3 次 |
| 課程通知 | 每堂課前一天（需準備材料時） |

**用座位表輪流覆蓋。** 不要每次都寫最活躍或最需要幫助的那幾個。

# 九、不可傳送的內容

| # | 不可傳 | 為什麼 |
|---|---|---|
| 1 | 孩子畫作的心理解讀 | 無實證依據，超出權責 |
| 2 | 任何診斷詞彙 | 過動、焦慮、憂鬱、自閉、發展遲緩 |
| 3 | 孩子的私密書寫 | U07⑦「花在等什麼」、U08⑥「想跟老師說的話」——除非事先問過孩子 |
| 4 | 通報內容 | 走正式管道，**不告知家長**（依主管與輔導室指示） |
| 5 | 其他孩子的資訊 | 包括「隔壁小朋友也……」 |
| 6 | 對孩子的性格評價 | 內向、自信、細心、沒耐心 |
| 7 | 作品排名或比較 | 「他這張是全班最好的」也不行 |
| 8 | 未經同意的照片 | 含臉的照片、公開展示、社群使用，各需分別同意 |
| 9 | 對其他家長的抱怨 | 任何形式 |
| 10 | 承諾超出能力的事 | 「我會幫他解決」「交給我就好」 |

## 傳送前的三個檢查

1. **這句話能被替換成別的孩子嗎？** → 可以，就是通用句，沒有價值。
2. **這句話有沒有「因為」「代表」「應該是」？** → 有，就是推論，刪掉。
3. **這句話如果被截圖轉傳，我還站得住嗎？** → 站不住，就不要傳。

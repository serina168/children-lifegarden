# 講義撰寫指令包（給 Claude Code 用）

使用方式：在 repo 根目錄開 Claude Code，依序貼上下面的指令。
指令 0 只需執行一次；之後每次要寫講義，貼指令 1（單元）或指令 2（整個系列）。

---

## 指令 0｜建立專案基礎（只做一次）

```
請閱讀 曼陀羅講師培訓/ 底下的 00_課程總覽.md、01～03 三份系列大綱、
以及 05_講義格式規範.md，還有 repo 根目錄的 教材內容總整理.docx。

接著：
1. 建立資料夾 曼陀羅講師培訓/講義/L1、/L2、/L3、曼陀羅講師培訓/附件
2. 在 曼陀羅講師培訓/CLAUDE.md 寫一份專案工作規則，內容包含：
   - 本專案的定位（兒童曼陀羅講師培訓教材，繁體中文台灣用語）
   - 05_講義格式規範.md 是最高準則，每次寫講義前必讀
   - 檔名規則與存放位置
   - 五條紅線（不談療效、不談宗教、不解讀畫作心理、不寫品牌、不抄襲）
   - 寫完一份講義就 commit 一次，commit 訊息格式：`docs: L1-U06 動物曼陀羅講義`
3. 建立 曼陀羅講師培訓/講義/_範本.md，內容是 05 規範中十四個章節的空白骨架
4. 建立 曼陀羅講師培訓/進度表.md，用 checkbox 列出三系列共 36 個單元，全部未勾選

不要在這一步寫任何講義內容。做完後列出你建立的檔案清單。
```

## 指令 1｜寫「一個單元」的完整講義（最常用）

把 `<<>>` 裡的內容換成你要的單元，其他照貼。

```
請寫出一份完整的單元講義。

【單元】<<系列一 單元 6：教案實作 A — 動物曼陀羅>>

【必讀】
- 曼陀羅講師培訓/05_講義格式規範.md（最高準則，逐條遵守）
- 曼陀羅講師培訓/01_系列一_低年級_Level1.md 中該單元的大綱條目
- 曼陀羅講師培訓/講義/_範本.md（章節骨架）
- 教材內容總整理.docx（沿用「生命主軸／生命教育核心／生命種子」語彙）

【要求】
1. 嚴格照 05 規範的十五個章節順序寫，不可增刪章節
2. 字數 3,000–4,500 字（不含表格與附件）
3. 第五章「兒童課教案」要做成逐分鐘流程表，總長 90 分鐘，
   欄位：時間｜段落｜教師行為｜學生行為｜教具｜引導語
4. 第四章「講師術科分解步驟」要寫 8–12 步，
   每一步都要有：動作說明／預估時間／關鍵提醒／新手最常犯的錯
5. 第七章五題狀況題，要是真的會在低年級教室發生的事，不要泛泛而談
6. 至少 3 處 `> 【插圖】…`，明確說明那張圖要拍／畫什麼
7. 附件要能直接影印給孩子用（學習單版面用文字排版描述清楚）
8. 第七章「兒童心理觀察」依規範第二之一節撰寫：指出本單元最能看見的
   一到兩個觀察向度、四種典型樣貌、事實句 vs 推論句對照、轉介判準。
   一律從創作歷程行為判讀，不得從畫面推測心理，不得使用診斷詞彙
9. 結尾「生命種子」寫成 2–4 行短句，語氣與《我的生命花園》一致

【輸出】
寫到 曼陀羅講師培訓/講義/L1/L1-U06_教案實作A_動物曼陀羅.md
寫完後更新 曼陀羅講師培訓/進度表.md 勾選該單元，並 commit。
不要問我問題，遇到細節不明的地方，用你的專業判斷補完並在檔案最後加一段
「【待確認】」列出你替我做的假設（最多 5 條）。
```

## 指令 2｜一次寫完「一整個系列」12 個單元

```
請依照 曼陀羅講師培訓/01_系列一_低年級_Level1.md，
逐一寫出單元 1 到單元 12 的完整講義，每個單元一個檔案。

規則同 指令 1（嚴格遵守 05_講義格式規範.md 的十五章節、字數、逐分鐘教案表）。

額外要求：
- 一次寫一個單元，寫完一個就存檔並 commit，再寫下一個，不要一次全部輸出到對話裡
- 十二個單元之間要有連續性：後面的單元可以回扣前面的技法，
  用「（見 L1-U03 紋樣 30 式）」這種方式互相引用
- 十二份講義的「引導語庫」不可重複，累積起來要像一本可用的話術手冊
- 五個觀察向度要平均分配到十二個單元，每個向度至少被深寫兩次，
  累積起來要能拼出一個孩子的完整輪廓
- 每寫完 4 個單元，停下來給我一份 100 字的進度回報

全部寫完後，額外產出：
曼陀羅講師培訓/講義/L1/L1-00_系列一講師手冊總覽.md
內容是：課程地圖、12 單元一頁式對照表、術科作品清單、認證流程、教具總表。
```

（要寫系列二／三時，把檔名 `01_…Level1` 換成 `02_…Level2` 或 `03_…Level3`，
`L1` 換成 `L2`／`L3` 即可；系列三每單元 3 小時，教案流程表請改成 120 分鐘。）

## 指令 3｜產出全套附件（學習單・表單・範本）

```
請閱讀 曼陀羅講師培訓/講義/ 底下所有已完成的講義，
彙整並產出下列附件到 曼陀羅講師培訓/附件/，每份獨立檔案：

1. 學習單總集.md — 每個單元一張，A4 單面，含標題、指令、作畫框、自評三格
2. 教師課堂觀察紀錄表.md — 可記錄 15 位孩子的專注度、參與度、特殊事件
3. 講師試教評量表.md — 三個系列各一份，含評分向度、配分、評語欄
3b. 學生歷程觀察手冊.md — 五向度觀察表（單堂版／學期彙整版）、
    事實句寫法對照、四種樣貌速查、與家長／導師的談話腳本、轉介流程圖
4. 家長溝通範本集.md — 開課通知、課後訊息 ×5、成果展邀請、期末回饋單
5. 材料採購總表.md — 三系列分開，欄位：品項｜規格｜數量｜單價｜單人成本｜備註
6. 課堂安全守則.md — 平面課／複合媒材課／立體木器課三版
7. 引導語手冊.md — 把所有講義的引導語庫抽出來，依情境分類重編

每份都要能直接列印使用。用表格與條列，不要長段落。
```

## 指令 4｜品質檢查（寫完後一定要跑）

```
請對 曼陀羅講師培訓/講義/ 底下所有 .md 檔做一次全面品質檢查，
產出報告到 曼陀羅講師培訓/品質檢查報告.md：

1. 【格式】每份是否具備 05 規範的十五個章節？缺哪些？
2. 【紅線】是否出現療效宣稱、宗教用語、畫作心理解讀、診斷詞彙、品牌名稱？逐條列出檔名與行號
2b.【觀察章】第七章是否全部從歷程行為出發？有沒有任何一句是從畫面推測心理？
   五個觀察向度在十二個單元的分布是否平均？
3. 【用語】是否有中國大陸用語或簡體殘留？列出並提出替換
4. 【重複】不同單元之間是否有大段重複內容？列出重複段落
5. 【難度】各單元的難度是否符合該年段？指出過難或過簡的地方
6. 【時間】每份的 90／120 分鐘教案流程表加總是否正確？
7. 【字數】各份字數統計表
8. 【觀察向度】列出十二個單元各自深寫了哪些向度，做成對照表

只出報告，先不要修改。報告最後給我一份「建議修正優先順序」清單。
```

## 指令 5｜排版輸出（要印成實體手冊時）

```
請把 曼陀羅講師培訓/講義/L1/ 的所有講義合併成一本可印刷的講師手冊：

1. 產出 曼陀羅講師培訓/輸出/系列一講師手冊.docx
   - 使用 docx skill
   - A4、含封面（書名／系列／版本／年份）、目錄、頁碼、頁眉（系列名）
   - 標題階層對應 Word 樣式，方便自動產生目錄
   - 每個單元從奇數頁開始
   - 表格加框線，引導語用淺色底
2. 圖片位置先放灰底佔位框，框內寫該處 `【插圖】` 的說明文字
3. 另外產出一份 曼陀羅講師培訓/輸出/系列一_插圖需求清單.md，
   列出所有佔位框編號、所在頁、要拍／畫的內容、建議尺寸

完成後告訴我檔案路徑與總頁數。
```

## 小技巧

- **一次一個單元品質最好**：指令 1 產出的密度比指令 2 高，趕時間才用指令 2。
- **接續修改**：`請把 L1-U06 的第七章狀況題從 5 題擴充到 10 題，其餘不動。`
- **調整深淺**：`L2-U03 對中年級來說太難了，請把第三章知識內容降階，並補一段「如果孩子聽不懂可以這樣說」。`
- **統一風格**：改完任何一份之後，跑一次 指令 4，避免各單元文風走鐘。
- 讓 Claude Code 每寫完一份就 commit，出問題可以隨時 `git diff` 回頭比對。

# Level 1 學習單｜可直接影印

12 張 A4 表單，用真正的方框、線條、格子繪製，**列印後即可影印發給孩子**。

## 檔案

| 檔案 | 用途 |
|---|---|
| `學習單_全套12張.pdf` | 一次印完整學期（12 頁） |
| `學習單01_….pdf` ～ `學習單12_….pdf` | 單堂課要用哪張就印哪張 |

## 列印設定

| 項目 | 設定 |
|---|---|
| 紙張 | A4 |
| 縮放 | **實際大小 / 100%**（不要選「符合頁面」，會縮小格線） |
| 單雙面 | 單面 |
| 色彩 | 黑白即可（版面未使用彩色油墨） |
| 建議份量 | 每種 = 班級人數 × 1.2（備品） |

## 版面規格

- A4 直式，四周邊界 15 mm
- 標題 23pt／題目 15pt／選項與詞彙 14–15pt／說明 11.5pt
- 方框、圓圈、色塊、書寫線皆為向量繪製，放大不失真
- 每張右下角有課程標記，左下角有單元編號

## 兩個設計重點（不要改掉）

**① 學習單 07 第 ⑦ 欄**印有「這一格只有你跟老師看得到」。
印了就必須做到——不公開朗讀、不轉述、不引用於家長訊息，除非事先徵得孩子同意。

**② 學習單 11 第 ⑤ 欄**的四個選項（要／換一張掛／掛在角落／今天先不要）
必須四個都印出來。印出來，孩子才會相信「今天先不要」是真的可以選。

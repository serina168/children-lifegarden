## 關於學習單與表單

Markdown 裡用 ASCII 字元畫的表單版面（學習單、同意書、紀錄表），
在轉換時已改為**加框的文字區塊**——內容完整，但**不是可直接影印的表單**。

要做成真正可填寫的表單，有兩條路：
1. 用 Word 版的文字內容，自行拉表格重排（最快）
2. 告訴我要哪幾張，我另外做成獨立的表單檔

各單元第十二章附件都附有版面規格（尺寸、字級、填寫時機），照著排即可。
